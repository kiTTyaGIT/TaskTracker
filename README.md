# Task Tracker - Платформа для управления задачами

## Описание проекта

Task Tracker - это бэкофис-система для управления задачами внутри команды. 
Система позволяет регистрировать пользователей (сотрудников) и объединять их в проекты, создавать и отслеживать задачи с различными статусами и приоритетами.

## Функциональные возможности

### Управление пользователями
- Регистрация и редактирование данных сотрудника
- Назначение ролей (менеджер, разработчик, тестировщик, аналитик)
- Объединение пользователей в проекты

### Управление проектами
- Создание и редактирование проектов
- Назначение сотрудников на проекты
- Отслеживание сроков выполнения

### Управление задачами
- Создание задач с атрибутами:
  - Статус ("Новая", "В работе", "Выполнена")
  - Приоритет (низкий, средний, высокий)
  - Исполнитель (один из пользователей системы)
  - Сроки выполнения (часы)
  - Описание задачи

#### "Бэклог" задач
- Отображение всех задач из всех проектов
- Фильтрация по:
  - Статусу
  - Приоритету
  - Исполнителю
    

### Инструкция по запуску

1. Клонируйте репозиторий:
```bash
git https://github.com/kiTTyaGIT/TaskTracker.git
```
2. Запустите приложение с помощью Docker Compose (в фоновом режиме):
```bash
docker compose up --build -d
```
3. После запуска фронтенд доступен по адресу: http://localhost:8051, бэкенд доступен по адресу http://localhost:8090
4. Остановка приложения 
```bash
docker compose down
```
6. Для полной очистки с удалением всей сохраненной информации:
```bash
docker compose down -v
```
